# NAMUA HyperFrames Editor 🎬

HyperFrames를 최종 렌더링 코어로 사용하면서, 영상·자막·이미지·음악을 **실시간 미리보기와 멀티트랙 타임라인에서 직접 조절**할 수 있도록 만든 Windows용 데스크톱 영상 편집기입니다.

## 이번 업그레이드의 핵심

- 타임라인 클릭·드래그와 미리보기 플레이헤드 즉시 동기화
- 재생 중 자막·이미지·텍스트 변경 즉시 반영
- 미리보기 화면에서 오버레이 직접 이동·크기 조절·회전
- 영상/자막/텍스트/이미지/배경음악 멀티트랙
- 클립 양끝 드래그 트림, `S` 분할, 리플 삭제
- 프레임 단위 이동과 타임라인 확대/축소
- 영상·음악 파형 표시
- 360p/540p/720p 프록시 자동 생성, 최종 출력은 원본 사용
- SRT/VTT 가져오기
- 자막 문구·글꼴·크기·색상·테두리·그림자·위치 실시간 편집
- 밝기·대비·채도와 페이드·슬라이드·줌 미리보기
- 자동 저장 및 프로젝트 복구
- HyperFrames CLI를 이용한 MP4 내보내기

## Windows 설치

1. Node.js 22 이상을 설치합니다.
2. `install_windows.bat`을 실행합니다.
3. 설치가 끝나면 `start_editor.bat`을 실행합니다.

PowerShell에서 직접 실행하려면:

```powershell
npm install
npm run doctor
npm run dev
```

## 주요 단축키

| 단축키 | 기능 |
|---|---|
| `Space` | 재생 / 일시정지 |
| `Ctrl+Z` | 실행 취소 |
| `Ctrl+Shift+Z`, `Ctrl+Y` | 다시 실행 |
| `S` | 플레이헤드 위치에서 자르기 |
| `Delete` | 선택 항목 삭제 |
| `←` / `→` | 1프레임 이동 |
| `Shift+←` / `Shift+→` | 1초 이동 |
| `Ctrl+마우스휠` | 타임라인 확대 / 축소 |
| `Home` / `End` | 영상 시작 / 끝 |

## 라이선스

이 프로젝트 코드는 Apache-2.0으로 배포합니다. HyperFrames도 Apache-2.0 라이선스입니다.
